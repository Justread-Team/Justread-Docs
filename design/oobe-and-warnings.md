# OOBE 与警告页

## 状态与图标

OOBE 仅用于系统资源缺失、资源下载或 USB 串口安装过程。主页扫描书库和 SD 卡移除后的重试属于 SD 重载，不应复用资源载入文案。

| 页面状态 | Lucide 图标 | 表达内容 |
| --- | --- | --- |
| 首次安装资源 | `file-input` | 需要从网络或电脑载入系统资源 |
| 资源下载中 | `arrow-down-to-line` | 正在通过 Wi-Fi 获取资源 |
| 资源载入完成 | `check-line` | 资源已校验并保存 |
| 资源载入失败或 SD 卡意外移除 | `file-exclamation-point` | 发生错误，等待重试或恢复 SD 卡 |
| SD 卡重载中 | `refresh-cw` | 重新挂载 SD 卡并扫描书库 |
| 设备致命错误 | `bug` | 设备发生错误并准备恢复 |

OOBE 和警告插画使用 256 × 256 px 物理槽、12 px 描边。图形必须使用对应的 Lucide 源 SVG，并遵守[点阵生成与高清化规范](/design/lucide-bitmap-assets)。标题和正文说明具体状态；图标不能代替错误原因、操作结果或重试入口。

## 扫描、下载与 SD 重载

| 界面动作 | 固件动作 | 目的 |
| --- | --- | --- |
| 主页文件按钮／扫描书库 | `RUI_ACTION_RESCAN` | 显示 SD 重载页，异步重挂载并扫描本地书籍；不检查或下载系统资源 |
| 通过 Wi-Fi 下载 | `RUI_ACTION_RESOURCE_DOWNLOAD` | 下载缺少的系统资源，并显示资源下载进度 |
| USB 串口载入 | USB 串口接收器写入系统资源 | 电脑端资源发送工具将系统资源写入 SD 卡；OOBE 显示载入进度 |
| SD 卡移除页重试 | `RUI_ACTION_RESCAN` | 与主页扫描共用 SD 重载流程；挂载成功后扫描书库并返回主页 |

Wi-Fi 和 USB 串口共用 OOBE 载入进度页，只有 Wi-Fi 按钮会触发网络下载。主页扫描和 SD 卡移除页重试只执行 SD 重载，不调用资源检查或下载。

SD 重载进度来自挂载时逐步降频重试的实际尝试阶段。SD 接口不提供字节级百分比，因此不能将它显示成文件下载进度。重载页标题写明“正在重载 SD 卡”，不能显示“正在载入资源”。
