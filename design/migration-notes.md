## 证据范围与处理顺序（补充说明）

上表沿用原草案对旧截图和 CSS 的描述。原始 `design.css` 仍未提供，表中的 CSS 数值不是本次重新验证的结果。后续已收到首页、书库、应用、设置与阅读设置五张参考图，保存在[系统组件留白](/design/spacing-and-regions#参考图)；其结构用于补充留白建议，不覆盖既有文字规范。

建议按“替换 Token → 计算文字容器 → 校正系统几何 → 移除多余装饰 → 检查热区 → 重算分页 → 实机刷新”的顺序处理。每项记录受影响页面、处理结果与证据；涉及灰阶、底部可见性或裁字的项继续保留实机待验证状态。
