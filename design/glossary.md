# 设计术语表

| 术语 | 含义 |
| --- | --- |
| Read Pico / 小纸 Pico | 目标硬件平台；默认684×1216竖屏 |
| JustRead | 适配目标硬件的阅读器固件项目 |
| 设计基线 | 目标规则集合；当前v0.2.1草案 |
| 固件版本 | 可刷写的软件版本，与设计版本独立 |
| 声明格式版本 | Mini App元数据结构版本，目前仅拟议 |
| Token | 集中维护的颜色、排版和留白等语义值 |
| 可见框 | 图标或文字实际占据的绘制边界 |
| 热区 / 命中区 | 接收控件输入的区域，可大于可见框 |
| 应用画布 | 系统分配给应用的完整绘制矩形 |
| 内容区 | 画布内应用实际排版的范围 |
| 系统交互保留区 | 系统独占命中范围，应用不可放置交互 |
| 整页分页 | 切换完整终态，不显示自然滚动中间位置 |
| 脏区域 / 变化区域 | 新旧内容变化、需清除或更新的矩形 |
| 局部刷新 | 更新部分区域；是否清理由驱动策略决定 |
| 全局刷新 | 全屏更新或清理，不绑定每次小变化 |
| 残影 | 旧显示状态留在新画面的可见影响 |
| DU / GL16 / GC16 | 官方Demo刷新模式标识，适用性需实测 |
| Mini App | 拟议应用单元，未定义实现技术或隔离机制 |
| 小组件 | 宿主分配内容区的嵌入展示，基准612×600 |
| Home | 返回桌面，不等同于Back或终止应用 |
| Back | 返回上一层，有临时界面时优先关闭 |
| 关机终态 | 正常断电前必要刷新后的最终显示，区别于锁屏 |
