# 设备适配与困难内容

- 基准设备先按 684 × 1216 设计并验收；其他设备以实际可用矩形、像素密度与输入方式适配。
- 不直接按分辨率比例缩小全部内容；保持可读字号和可操作热区，优先减少列数／行数并增加分页。
- 较大屏幕可增加列数与留白，不能把 3×4 永久视为所有设备的上限。
- 不把 612 × 600 小组件强行塞进更小宿主；未来宿主应协商尺寸或提供专门模板。
- 横屏需要独立评审；不能认为旋转整个竖屏位图就是完整适配。
- **补充建议**：支持字号放大并重新分页，不因放大造成条目切半、按钮消失或横向溢出。
- 检查最长书名、长作者名、无空格英文、混合语言、100% 电量、无网络、无封面、空列表、第一页／末页和字体缺字。
- 错误／断网／加载中不清空仍然可用的数据；使用静态说明区分旧数据与最新结果。

## 内容与边界样例（补充建议）

| 样例 | 检查重点 | 推荐处理 |
| --- | --- | --- |
| 超长书名、作者、无空格英文 | 必要识别信息与横向溢出 | 换行、摘要和完整详情入口 |
| 100% 电量与多个状态 | 是否侵入中线 | 隐藏次要状态，不缩小文字 |
| 字体缺字 | 关键操作是否可读 | 覆盖校验、适当回退与说明 |
| 字号放大 | 条目与按钮是否完整 | 重算容量、减少同页项目 |
| 页面变短 / 变空 | 旧像素是否残留 | 更新完整容器与指示器 |
| 更新后页数减少 | 页码是否失效 | 回到有效页并修正选择 |
| 更小的小组件宿主 | 是否盲目缩放和裁切 | 协商模板或明确不兼容 |

完整异常状态见[交互状态表](/design/interaction-and-states)。缺失封面时仍需从文字入口识别书籍。
