# 快速开始

## 阅读者

### 刷入 JustRead

在线刷机页从 Cloud 的型号清单读取支持设备，再按所选型号的 `web-flash.json` 获取分区地址和镜像摘要。请使用 HTTPS 页面和 Chrome 或 Edge，通过 USB 连接设备并选择对应型号。页面写入前会校验 Bootloader、分区表、OTA 启动数据和应用镜像的大小与 SHA-256，写入后逐分区回读校验；它不会擦除整片 Flash，NVS、SPIFFS 和 SD 卡文件会保留。USB 串口只能识别芯片，无法替用户确认产品型号。

普通 SD OTA 使用单独的应用 `firmware.bin`，只更新备用应用槽位，不能代替首次安装或分区表迁移所需的网页分区刷写。

### 完成首次启动

1. 插入 SD 卡并开机。书籍放在 SD 卡 `/books/`，支持 `.txt` 和 `.epub`。
2. 如果设备提示缺少系统资源，选择 Wi-Fi 下载，或在 HTTPS 在线刷机页选择 **通过 USB 导入资源**。USB 导入需要设备已启动、插入 SD 卡并保持 USB 连接。
3. 系统字体校验完成后，可在设备上登录/注册 Reader Cloud 账户，也可选择暂不使用并进入书架。云同步是可选功能。
4. 把 TXT/EPUB 文件放入 `/books/`，回到书架选择 **扫描 SD 卡**。打开书籍即可阅读。

### 日常基本操作

- 阅读时左右滑动或使用左右键翻页；点击正文打开阅读工具。工具中有目录、书签、搜索、页码/进度跳转、返回原位置、图片和字体设置。
- 底部导航在首页、书架、应用和设置之间切换。阅读页中键双击可返回书架，其它页面中键长按可返回书架；设备上的电源键短按用于从锁屏返回。
- 设置中的文件传输可通过设备热点、当前 Wi-Fi 或 USB 读卡访问 SD 卡。云端同步需要连接 Wi-Fi 并绑定账户。

更详细步骤见[首次使用](/user/getting-started)、[阅读与文件管理](/user/reading-and-files)及[设置与更新](/user/settings-and-updates)。
