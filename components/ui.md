# 界面组件

## 结构

`include/reader_ui.h` 定义可移植的 `rui_state_t`、视图、事件、动作和绘制回调；`src/reader_ui.c` 实现书架、阅读、目录、书签、搜索、跳转、Wi-Fi、连接、文件传输、OTA、应用和 OOBE 页面。`src/rui_chrome.c` 负责通用页面顶栏和底部导航；`include/rui_tokens.h` 提供编译期尺寸和颜色 token。

平台通过 `rui_painter_t` 提供文本测宽、矩形、线条、文字和图片绘制函数。测宽和绘制应使用同一字体。UI 不在 render 回调中读取 SD 卡或访问设备服务；它将操作表达为 `rui_action_t`，由 `ports/read_pico/app_reader_ui.c` 执行副作用，再更新 UI 状态。

## 主要界面

- 首页和书架提供继续阅读、最近阅读和书籍列表/网格。
- 阅读视图管理章节分页、图片命中区域、工具栏、书签、搜索和跳转。
- 设置分根类别和阅读子项；设备功能由固件集成层响应。
- 应用页运行 SD 卡 Lua 插件；插件不是 Mini App，也不使用设计稿中的应用声明协议。
- OOBE 和恢复页检查系统字体及 SD 卡状态，在资源校验通过前限制进入正常阅读流程。

布局尺寸在构建时生成，单个 `rui_state_t` 含有较大的页面状态，设备端将其放入 PSRAM，不能把完整状态对象放到小任务栈。
