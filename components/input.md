# 输入与按键

## 设备输入

小纸 Pico 端口读取 CST836U 触摸控制器和设备三键输入。触摸采样由 `ports/read_pico/reader_input_esp.c` 的独立任务执行；UI 状态、字体绘制和推屏仍由主应用循环负责。区域和手势事件经 `components/reader_support/reader_input_queue` 有界排队。

## 用户操作

| 输入 | 当前 UI 语义 |
| --- | --- |
| 左右滑动 | 阅读时上一页/下一页；列表或设置按页面逻辑响应 |
| 左右物理按键 | 阅读时翻页；列表中可切换页面 |
| 中键短按/触摸 | 激活焦点或打开正文阅读工具 |
| 中键双击 | 阅读时返回书架 |
| 中键长按 | 从多数子页面返回书架；阅读页不处理长按返回 |
| 点击页面控件 | 由当前 UI 命中区域映射为应用动作 |

手势在输入采样阶段转换为语义事件；不要在触摸采集任务中直接访问 UI 状态或调用显示驱动。阅读队列在黑白模式最多缓存 3 个待处理翻页请求，灰度模式最多缓存 2 个；队满时新请求会被丢弃。模式变化或离开阅读时会清理旧请求。
