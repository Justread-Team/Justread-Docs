# 安装和使用插件、锁屏

这篇面向只想使用现成扩展的读者。安装别人制作好的插件或锁屏，不需要会 Lua，也不需要编译、刷写固件。以下操作依据当前小纸 Pico 固件源码整理；菜单文字可能随版本调整。

## 插件和锁屏有什么区别

**插件**是从应用列表中打开的小程序，例如计算器、棋类游戏。你打开它，它才运行；退出后回到系统界面。

**锁屏模板**决定设备锁定时显示什么，例如一句文字、书籍插画、每分钟更新的时钟。先在设置中选好模板，之后锁屏时系统才使用它。模板可以完全没有程序代码，也可以附带一段 Lua 更新时钟或通知。

| 你收到的文件 | 用途 | 从哪里使用 |
| --- | --- | --- |
| `名字.jrpack` | 打包好的普通插件 | 应用中的插件导入入口 |
| 含 `main.lua` 的文件夹 | 普通插件源码目录 | 复制到 SD 卡插件目录，再从应用列表打开 |
| `名字.lspack` | 打包好的锁屏模板 | 阅读设置中的锁屏模板入口 |
| `名字.zip` 或一个开发源码目录 | 可能是作者的源文件 | 先看作者说明；不能仅改后缀就认为是合格安装包 |

`.jrpack` 和 `.lspack` 都使用 ZIP 容器，但有指定的入口、目录布局和不压缩要求。给普通用户的安装包应已经由作者做好，不需要自己解压或重新压缩。

## 先把文件放进 SD 卡

可以使用设备的“设置 → 文件传输”，通过设备显示的网页地址传输文件，也可以使用 USB 读卡模式。USB 读卡完成后，在电脑上安全弹出，让设备返回系统。具体传输入口见[阅读与文件管理](/user/reading-and-files)。

下文所有以 `/` 开头的 SD 路径，都从**存储卡根目录**开始算，不是电脑硬盘根目录。例如卡在电脑上显示为 `READER`，`/.justread/screen/` 就表示 `READER` 里的 `.justread` 文件夹，再进入 `screen`。

`.justread` 以点开头，部分电脑文件管理器会隐藏它。看不到时启用显示隐藏文件，不要另建一个不带点的 `justread` 文件夹。

## 安装一个普通插件

### 收到的是 .jrpack

1. 把 `.jrpack` 放进 SD 卡一个便于找到的目录。
2. 在设备打开应用/SD 卡 Lua 插件页面，选择“导入 .jrpack”。
3. 在文件浏览器中找到刚才的包，选择导入。
4. 导入成功后回到插件列表，点开对应项。

导入会把包复制到系统的插件目录。只把文件放进卡里不会自动打开插件；需要回到列表启动。

当前本地包模式主要从包内运行 `main.lua`，附属图标和存档支持有限。如果作者说明“请用目录安装”，按下面的方法操作；包能打开但图标缺失、退出后记录丢失时，也先确认安装方式。

### 收到的是含 main.lua 的文件夹

例如作者提供 `counter` 文件夹，把它整体复制到：

```text
SD 卡根目录/
└── .justread/
    └── plugins/
        └── counter/
            └── main.lua
```

正确入口是 `/.justread/plugins/counter/main.lua`。常见错误是复制成 `counter/counter/main.lua`，多了一层目录，设备便找不到入口。

退出文件传输后重新进入插件列表。目录模式适合需要私有存档或导航图标的插件。插件列表最多发现 16 项，名称使用英文字母、数字、短横线等简单字符，避免过长或使用中文目录名。

### 从云市场安装

先连接 Wi-Fi 并登录/绑定 Reader Cloud 账户，在插件市场刷新目录，选择已审核版本安装。安装后从本地列表或市场提供的打开入口运行。

当前市场安装只部署普通插件的入口源码；作者不能假设包内的附属图片会同时落地。选择插件时查看作者的兼容性和安装说明。

### 怎么退出

点击插件顶栏的系统返回按钮。当前小纸 Pico 固件的普通实体键回调也会退出插件。不同插件在画布里的“返回”“退出”等按钮由作者实现，不要把其行为与系统返回混淆。

## 安装并启用一个锁屏

1. 把 `.lspack` 放进 SD 卡。
2. 在阅读设置打开“锁屏模板”，选择“从 SD 卡选择 .lspack”。
3. 找到包并导入。当前实现会验证模板，成功后设为当前模板。
4. 让设备进入锁屏，检查是否出现新模板。
5. 锁屏后短按电源键解锁，返回此前界面。

也可把包直接放到 `/.justread/screen/`，再到模板列表选择。列表通常显示模板内部写的名称，所以它可能与文件名不同。云端锁屏市场同样需要联网和账户。

自动锁屏时间在阅读设置中，默认 5 分钟；设为 0 表示关闭自动锁屏。安装模板不会自动改变这个时间，也不会让设备立即锁屏。

## 为什么有些锁屏不动，有些会更新

静态模板只显示一张由图片和文字组合的画面；没有更新任务是正常的。

动态模板可以声明多久检查一次时间或其他内容。墨水屏刷新需要时间，所以“一分钟更新一次”不等于秒针连续移动。锁屏期间系统是否校过时间、是否有诗库、手机是否允许通知共享，也会影响显示内容。

| 现象 | 先检查什么 |
| --- | --- |
| 插件未出现在列表 | 是否多套一层目录、是否叫 `main.lua`、名称是否过长、是否超过 16 项 |
| 插件打不开或返回列表 | 是否适用当前固件；向作者提供包版本、设备版本和错误提示 |
| 自定义导航图标变成默认图标 | 是否用了本地包或市场入口安装，而作者要求目录安装 |
| 计数/游戏记录退出后丢失 | 是否为本地直接运行 `.jrpack`；作者是否实现存档并处理失败 |
| 选了模板却看到默认画面 | 配置、图片、字体或 Lua 可能未能加载；先换回已知正常模板 |
| 时间为 `--:--` | 系统时间可能尚未校准，模板以占位文本继续显示 |
| 有时钟但没有 iPhone 通知 | 模板是否支持通知；手机配对及通知共享是否允许；当前是否确有通知 |
| 等一会儿仍不自动锁屏 | 自动锁屏是否设为 0；期间是否一直有触摸或按键操作 |

## 想自己改一点内容

只想改锁屏上的一句文字，可以从[第一个锁屏](/developer/lockscreen-tutorial)开始：先编辑两份文字配置，不需要先学 Lua。想做能点击的计数器，可以从[第一个插件](/developer/plugin-tutorial)开始。

开发教程会说明哪些文件要改、修改后应该看到什么，以及怎样重新打包。不要直接用普通压缩软件的默认压缩方式覆盖安装包。
