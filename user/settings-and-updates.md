# 设置与更新

## 设置页面

设备设置按当前固件页面分组：

| 页面 | 当前提供的功能 |
| --- | --- |
| Wi-Fi | 扫描附近网络、选择网络、输入密码、查看连接状态和地址；成功连接的网络保存在 NVS 并用于后台重连 |
| 文件传输 | 开启设备热点或复用当前 Wi-Fi 访问 SD 卡；进入 USB 读卡模式；云同步构建还提供从云端拉取缺失书籍 |
| 连接 | 查看 Reader Cloud 账户状态、登录/注册或扫码绑定、同步书架；打开插件市场和锁屏市场 |
| 阅读 | 字体、字号、行距、首行缩进、全屏黑白/灰度模式、残影清理、自动锁屏时间、锁屏模板 |
| 应用 | 启动 SD 卡 Lua 插件、导入 `.jrpack`、打开插件市场 |
| 设备 | 查看电量、面板温度和 SD 状态，重新读取设备数据，短鸣蜂鸣器 |
| 软件更新 | 检查、跳过或稍后处理固件更新；下载并安装更新，或从 SD 卡安装已有镜像 |
| 书库 | 重新扫描 SD 卡书籍 |
| 关于 JustRead | 查看设备软件信息 |

自动锁屏默认为 5 分钟，可设为 0–1440 分钟；0 表示关闭。锁屏只锁定界面和输入，不进入整机深度睡眠。锁屏时短按电源键返回此前页面。

## 设备内更新

设备需要先连接 Wi-Fi。固件从 `https://cdn.xmoa.smn.icu/downloads/release.json` 检查版本、更新说明、应用镜像大小和 SHA-256。出现更新提示后可选择更新、跳过该版本或稍后处理；跳过的版本保存在设备 NVS。

选择更新后，设备先把单独的 ESP32-S3 应用镜像下载到 SD 卡 `/.justread/ota/firmware/firmware.bin`，校验后写入备用 OTA 槽位，再切换启动分区并重启。也可把匹配的 `firmware.bin` 放到该目录，在软件更新页面选择 **从 SD 卡刷**。更新期间保持供电并勿移除 SD 卡。下载、镜像校验或写入失败时不会切换启动分区；新固件完成首次正常 UI 刷新后才确认启动，确认前异常重启可回滚。

发布更新固定使用 JustRead CDN 和发布清单中的摘要。SD 卡 `/.justread/ota/config.ini` 仅用于兼容的手动配置路径，下载地址仍须符合固件的 CDN 限制；不要把 16 MiB 全量刷写镜像或 ZIP 包放进 OTA 目录。

## 在线全量刷写与恢复

在线刷机页下载的是 16 MiB 全量镜像，并从 Flash 地址 0 写入。它用于首次安装、分区表迁移或恢复设备；会覆盖设备 Flash，包括分区表和 NVS。请先备份阅读进度和设备设置。固件包中的 `flash_args.txt` 也可用于命令行完整刷写。

设备内 SD OTA 只更新备用应用分区，不更新分区表。首次从旧分区表迁移时使用在线刷机页或固件包的完整 USB 刷写步骤；不要用 SD OTA 迁移分区表。

更多分区地址、镜像校验和回滚边界见固件仓库 `components/reader_ota/README.md`。刷写页选项和首次资源导入见[在线刷机](/flash/)及[首次使用](/user/getting-started)。
