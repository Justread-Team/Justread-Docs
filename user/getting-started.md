# 首次使用

适用设备：小纸 Pico ESP32-S3，16 MiB Flash，1216 × 684 实际面板。固件构建使用 684 × 1216 竖屏逻辑坐标。在线刷写或资源导入需要 USB 数据线；设备使用 SD 卡保存书籍、系统字体、用户字体、插件和锁屏包。

## 安装 JustRead

打开站点的[在线刷机](/flash/)页面，使用 HTTPS 下的 Chrome 或 Edge：

1. 连接小纸 Pico，在设备型号列表中选择 **小纸 Pico**。
2. 点击连接并在浏览器弹窗中选择设备 USB 串口。
3. 确认刷写，保持设备和 USB 连接，直到页面写完并回读校验清单中的分区，然后复位设备。
4. 刷写页从 Cloud 型号清单读取分区地址，当前会写入 Bootloader、分区表、OTA 启动数据和 JustRead 应用，不会擦除整片 Flash；NVS、SPIFFS 和 SD 卡文件会保留。USB 串口只能识别芯片，无法确认设备产品型号，请先核对选择。

## 安装首次启动字体

首次启动时插入 SD 卡。若系统字体尚未安装，设备会进入资源引导，显示 Wi-Fi 下载和 USB 导入入口。

- **USB 导入**：设备保持开机并连接 USB；在电脑上打开 HTTPS 在线刷机页，进入 **通过 USB 导入资源**。网页根据 Cloud 发布清单下载共享系统字体，使用 USB 串口写到 SD 卡并由设备校验。
- **Wi-Fi 下载**：在引导页连接 Wi-Fi，然后下载系统字体。设备会验证资源身份后保存到 `/.justread/system/fonts/system.ttf`。

系统字体为引导和系统界面资源。有效字体就绪后，可选择登录/注册 Reader Cloud 账户，也可以跳过云服务直接进入书架。账户密码只用于登录请求，不作为设备上的长期密码保存。

## 放入第一本书

可在电脑上直接写入 SD 卡，也可用设备 **设置 → 文件传输** 提供的热点、局域网或 USB 读卡功能。把 `.txt` 或 `.epub` 放入 SD 卡 `/books/`，然后在设备书架执行 **扫描 SD 卡**。书架识别到文件后，点选书名即可打开。

## 连接 Wi-Fi 与云账户

在 **设置 → Wi-Fi** 扫描并连接网络。Wi-Fi 会在离开设置页后保持连接，并尝试重连已成功连接过的网络。需要云同步、插件市场或锁屏市场时，在 **设置 → 连接** 登录/注册账户或启动扫码绑定，再按页面状态完成授权。

首次资源引导、刷写与 SD OTA 的差异见[设置与更新](/user/settings-and-updates)。
