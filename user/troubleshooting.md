# 故障排查

## 设备没有进入书架

- 确认 SD 卡已插入。若页面显示 SD 卡错误，插卡后点 **重试**；进入系统后可到书库重新扫描。
- 书籍必须位于 SD 卡 `/books/`，扩展名为 `.txt` 或 `.epub`。新增或移动文件后重新扫描。
- 单次书架扫描最多列出 64 本书。隐藏文件和不支持的扩展名不会作为书籍显示。

## 首次启动提示缺少系统资源

确认 SD 卡可写且有足够空间保存系统字体。选择 Wi-Fi 下载并检查网络，或使用 HTTPS 下的 Chrome/Edge 在线刷机页通过 USB 导入。导入后点 **重新检查**；资源校验通过才可完成引导。不要用用户字体替代 `system.ttf`。

## Wi-Fi 或云端操作失败

- 先在 **设置 → Wi-Fi** 扫描并连接网络，检查页面显示的连接状态和 IP。
- 云同步、插件市场和锁屏市场需要 Reader Cloud 账户绑定。账户登录、配对或目录下载失败时，检查网络连通性和设备时间，再重试。
- OTA 使用 HTTPS，证书校验需要有效系统时间；设备会尝试联网校时。OTA 发布地址和镜像摘要由 CDN 发布清单提供。

## 更新没有完成

保持供电并确认 SD 卡未拔出。OTA 下载失败时检查 Wi-Fi、SD 卡剩余空间及网络；从 SD 卡安装时确认文件位于 `/.justread/ota/firmware/firmware.bin`，且是小于当前应用槽位的单独 ESP32-S3 应用镜像。下载或校验失败不会切换启动分区，可重新尝试。

若设备无法正常启动，SD OTA 不能修复分区表。使用在线刷机页重新写入型号清单中的 Bootloader、分区表、OTA 启动数据和应用镜像。刷机页不会擦除整片 Flash，NVS 和 SPIFFS 会保留；确认选择的设备型号与实机一致。

## 文件传输或 USB 导入失败

- 热点/局域网传输时，让电脑连接页面显示的设备热点或与设备处于同一网络，并使用当前页面显示的地址和访问码。
- USB 读卡模式下，电脑安全弹出 SD 卡后再在设备上退出；设备会重启并重新挂载 SD。
- 在线刷机页的 USB 字体导入要求设备已启动、已插入 SD 卡，并由浏览器重新选择正确的设备串口。

仍无法解决时，请记录设备页面提示、固件版本、硬件修订、传输方式和 SD 卡格式，并提供串口日志。日志可能包含设备网络状态，不要公开 Wi-Fi 密码或账户凭据。
