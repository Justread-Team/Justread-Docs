# 阅读与文件管理

## 书籍格式与 SD 卡目录

设备从 SD 卡 `/books/` 扫描书籍，支持 `.txt` 和 `.epub` 扩展名（大小写不敏感）；书架常规扫描读取此目录下的文件，最多显示 64 本书。TXT 自动识别 UTF-8 或 GBK 并转换为内部 UTF-8；EPUB 按章节读取，支持章节目录、阅读进度和书内本地 PNG/JPEG 图片。损坏、加密或结构不兼容的 EPUB 可能无法打开。

| 内容 | SD 卡位置 | 支持内容 |
| --- | --- | --- |
| 书籍 | `/books/` | `.txt`、`.epub` |
| 用户字体 | `/fonts/` | `.ttf` |
| 系统字体 | `/.justread/system/fonts/system.ttf` | OOBE、系统界面及缺字回退 |
| Lua 插件 | `/.justread/plugins/<名称>/main.lua` | UTF-8 Lua 文本，详见[插件 API](/developer/lua-plugin-api) |
| 锁屏模板 | `/.justread/screen/*.lspack` | ZIP_STORED 锁屏包 |

在书架点击 **扫描 SD 卡** 后重新读取 `/books/`。书籍书签与阅读进度按书籍身份保存；字体、字号、行距、首行缩进和阅读刷新模式保存在设备 NVS。移除 SD 卡前先退出书籍，重新插卡后扫描书架。

## 阅读操作

- 左右滑动、左右按键和屏幕页脚按钮翻页。轻点正文打开阅读工具；阅读页中键双击可返回书架。
- 阅读工具包含章节目录、添加/查看书签、整书搜索、页码或全书进度跳转、返回跳转前位置、查看本章图片、选择字体和系统设置。
- 搜索可输入拼音、英文或数字；中文内容可按全拼或首字母检索。搜索结果定位到正文位置。
- 字体、字号、行距或首行缩进变化后会重新分页，并按正文位置恢复阅读。EPUB 进度保存章节和章节内 UTF-8 文本偏移；页面序号可能因排版变化而改变。
- 阅读设置可选择全屏黑白或全屏 16 灰度翻页。其它界面与安全局部刷新使用的波形由固件和面板驱动决定。

## 传输书籍和插件

**设置 → 文件传输**提供设备热点、当前 Wi-Fi 局域网和 USB 读卡。热点或局域网模式在浏览器访问设备提供的 SD 卡页面；页面显示访问地址和访问码，单个上传文件上限为 2 GiB，同名文件不会被覆盖。USB 读卡会重启进入 USB 大容量存储模式；电脑安全弹出后设备返回系统。

插件页可从 SD 卡导入 `.jrpack`，插件市场可下载已审核版本。插件源代码不进入固件；设备从 SD 卡加载。锁屏模板使用独立 `.lspack` 格式，不会作为普通 Lua 插件运行。具体操作见[安装插件和锁屏](/user/extensions)；想自己制作时，按[扩展入门路线](/developer/extensions)阅读。
